千寻 文件秒搜 1.2.2（Windows 原生版）
=====================================

Everything 式文件名秒搜：全盘文件名索引常驻内存，输入即出结果；新建、改名、删除约 1 秒内同步。
原生程序，无需 Python，无需安装，无需管理员权限。Windows 7 SP1 到 Windows 11 都能用。

一、版本选择
  qianxun-1.2.2-windows7-x64.zip：64 位系统（绝大多数电脑，含 Windows 7 64 位）。
  qianxun-1.2.2-windows7-x86.zip：32 位系统（右键“计算机”→ 属性 → 系统类型显示“32 位操作系统”时选它）。
  Python 版不能在 Windows 7 上运行，请用这里的原生包。

二、使用
  1．解压后顶层是 QianXun.exe 和 QianXun 文件夹。双击旁边的 QianXun.exe。
  2．exe 自带千寻图标。第一次打开主窗口时，会在桌面建立快捷方式。
  3．首次启动扫描全部本地磁盘，状态栏显示进度；之后从缓存秒开，后台自动同步变化。
  4．关闭窗口时程序最小化到任务栏通知区域，继续实时索引；右键托盘图标可退出。

三、搜索语法（与 Everything 一致，F1 查看完整说明）
  空格＝与　|＝或　!＝非　* ?＝通配符　"…"＝短语
  含 \ 或 / 的词按完整路径匹配（/ 等同 \）：Users\文档　d:/项目 报告
  ext:pdf;docx　size:>100mb　dm:today　file:　folder:　regex:　path:

四、常用快捷键
  Ctrl+Alt+F　全局唤出／隐藏（工具 → 选项中可修改或关闭）
  Enter 打开　Ctrl+Enter 打开所在文件夹　Ctrl+C 复制文件　Ctrl+Shift+C 复制路径
  F2 重命名　Delete 移到回收站　Alt+Enter 属性　Shift+右键 系统完整右键菜单
  Ctrl+I 区分大小写　Ctrl+B 全字匹配　Ctrl+U 匹配路径　Ctrl+R 正则

五、选项（工具 → 选项）
  · 索引范围：默认所有本地磁盘；可改为指定文件夹。
  · 可移动磁盘（U 盘、移动硬盘）：插入后自动加入索引，拔出后自动移除；“安全弹出”时程序立即释放该盘。
  · 网络驱动器：默认不索引，可勾选开启。
  · 登录 Windows 时自动启动（后台托盘）；工具 → 创建桌面快捷方式。
  内置排除：各盘 $Recycle.Bin、System Volume Information，以及 Windows\WinSxS。
  U 盘、网络盘上的文件不提供“移到回收站”（Windows 在这些盘上会直接永久删除）。

六、数据位置与卸载
  配置、索引缓存、日志：%LOCALAPPDATA%\QianXun\（config.ini、index.bin、qianxun.log）
  便携模式：在 exe 同一目录新建空文件 portable.txt，数据改存到同目录的 data 文件夹，整个文件夹可随 U 盘带走。
  卸载：退出程序，删除 exe 与 %LOCALAPPDATA%\QianXun\；若开启过自启，先在选项中取消。

七、常见问题
  · 首次运行出现“Windows 已保护你的电脑”：程序未做数字签名，点“更多信息 → 仍要运行”。用 U 盘拷贝的一般不会出现。
  · 从网上下载的压缩包：建议先右键 → 属性 → 勾选“解除锁定”，再解压。
  · 无权限访问的目录（其他用户的文件夹等）会静默跳过。普通用户无法读取 NTFS 主文件表，首次建索引按目录扫描，C 盘约需几十秒。
  · 联接点、符号链接只作为条目收录，不进入其中，避免重复和循环。
  · 问题排查：工具 → 打开日志目录，查看 qianxun.log。
